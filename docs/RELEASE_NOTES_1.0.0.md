# Release Notes — Offline Transcriber 1.0.0

Offline Transcriber 1.0

• Private on-device audio transcription with no cloud dependence
• Record meetings & lectures with synced timestamped playback

• On-device Study Mode: Key points, chapters, flashcards & quizzes (Pro)
